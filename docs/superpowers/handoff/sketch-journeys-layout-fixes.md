# PR 19 layout sketch: the play bar on a short game box (plan item 12)

Phone upright, a thing picked before Play: its settings sheet stays up, so the game box is 374 x 245.

Now (strip open, bar 266 x 132 top left over the hero's start):

```
+----------------------------+
| [|| ] [gauge] [again] [pin] |  <- play bar, with the 30 second strip under it
| Drag back ........ 0:01     |
| ======================o    |   the hero (start, tile 2.5, 7.5) is under here
|  wall            crate     |
+----------------------------+
```

Proposed (strip folds behind its own icon when the box is under 320 high; the bar is one row, 58 high):

```
+----------------------------+
| [|| ] [gauge] [again] [pin] [clock] [full]  <- the clock icon opens the strip; closed again by the same icon
|                            |
|   hero    crate            |   hero in sight, nothing over it
+----------------------------+
```

Phone sideways (700 x 318 box) is the same: the one row bar, the strip behind the clock icon. The icon is 48 x 48, has the spoken name "Drag back to see it again" and the same words as its tooltip. When the person opens the strip it opens as its own row under the bar, held open until the icon is pressed again; it is the person's choice and the game is held still while they look back. The bar stays top left on every level, so a person always knows where to find it.
