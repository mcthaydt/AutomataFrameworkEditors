# AutomataFrameworkEditors

The editors for games made with [AutomataFramework](https://github.com/mcthaydt/AutomataFramework). A team opens its
game from its GitHub repository and changes its authorable content (the JSON files; the code is the agents' work)
by touch on an iPad. Anyone can try it and keep a copy without signing in. Saving into the game needs a sign-in:
the game's owner chooses what each person may do (look, suggest, approve, edit), and people need GitHub only to
sign in.

Nothing is built yet. The first milestone's plan is
[`docs/superpowers/plans/2026-11-13-m1-thin-thread-editors.md`](docs/superpowers/plans/2026-11-13-m1-thin-thread-editors.md),
and [`docs/superpowers/progress.md`](docs/superpowers/progress.md) says where the work is.
